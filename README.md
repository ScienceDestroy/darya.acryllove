# Palette Creator by darya.acryllove

Конструктор выкрасок акриловых маркеров и трекеров раскрасок — http://dacryllove.ru

Статический сайт без сборки: `index.html`, `css/styles.css`, `js/*.js`. Работает на GitHub Pages как есть.

## Файлы

- `js/engine.js` — раскладка и рисование. Все размеры в миллиметрах. Одна и та же раскладка рисуется
  в SVG (превью и печать через браузер) и в canvas (PDF), поэтому они совпадают.
- `js/app.js` — интерфейс: формы, маркеры, наборы, печать/PDF, калибровка, обмен ссылкой.

## Точная печать

- PDF создаётся точно в размер листа (A4 = 595.276 × 841.890 pt), печатать с масштабом 100%.
- Печать через браузер: `@page` задаётся в мм, поля 0.
- Вкладка «Печать»: поля принтера (непечатаемая зона с предупреждениями), тестовая страница
  с линейками 100 мм и «лесенкой» у краёв, поправка масштаба и сдвига под конкретный принтер.

## Наборы маркеров

Во вкладке «Наборы» можно сохранить текущий список, создать набор из кодов (с диапазонами вида `Y01-Y17`),
обновить, переименовать, удалить, а также экспортировать и импортировать наборы файлом.
